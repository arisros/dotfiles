# OpenCode Project Template

This folder is a reusable project-local OpenCode setup.

## Use

Run OpenCode from the repository root so this config is auto-detected.

## Included

- `agent/project-architect.md` - planner-style project agent
- `skills/backend-engineer/skill.yaml` - backend-focused skill defaults
- `skills/frontend-engineer/skill.yaml` - frontend-focused skill defaults
