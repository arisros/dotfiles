## Focus

- Keep workflow code deterministic and side-effect free.
- Move external I/O to activities with idempotent semantics.
- Define retry policies, timeouts, and compensation intentionally.

## Validation

- Verify workflow/activity boundaries and data contract stability.
- Add tests for retries, cancellations, and failure recovery.
