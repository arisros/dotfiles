## Focus

- Keep reactivity explicit; avoid hidden state coupling.
- Use composable primitives and clear component boundaries.
- Preserve accessibility and responsive behavior by default.

## Validation

- Test user-critical flows and loading/error states.
- Verify server/client rendering assumptions if SSR is used.
