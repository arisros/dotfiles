# OpenCode Template Starter

Use this to scaffold project-local OpenCode config in any repository.

## Command

```bash
~/dotfiles/__scripts__/opencode_scaffold_template.sh /path/to/project
```

Overwrite existing `.opencode` in target repo:

```bash
~/dotfiles/__scripts__/opencode_scaffold_template.sh /path/to/project --force
```

## Prompt Template

See `prompt-template.txt` for a reusable prompt if you want an agent to generate a custom variant.
